# Basic Menu Cart System (Python)
## 📌 Project Description

This is a simple Python console-based food ordering system.
The program displays a menu with food items and their prices. The user can select items from the menu, add them to a cart, and the program calculates the total bill.

This project demonstrates basic Python concepts such as:

Dictionaries

Loops

Lists

User input

String formatting

## Features

Displays a menu with food prices.

Allows users to order multiple food items.

Stores ordered items in a cart.

Calculates the total bill automatically.

Simple command-line interface.

## Technologies Used

Python 3

Command Line / Terminal

## How to Run the Project

Install Python 3 on your system.

Download or clone the project.

Open a terminal in the project folder.

Run the program using:

python basic_menu_cart.py
